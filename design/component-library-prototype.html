Where these go

Each component above replaces or augments something already in the ContentOS pages. Command palette wires into the header search field. Dropdown menus hang off split publish buttons and table row triple-dots. Dialogs front the Reject Idea / Confirm Publish flows. Sheet powers New Article Idea. Popover reveals keyword density on click. Tooltips replace every title="" attribute. Switches drive Workflow Settings. Select replaces the placeholder dropdown styling. Toast confirms publishes and surfaces failures. Hover Card previews articles from the dashboard table. Skeleton renders while fetching. Date Picker schedules publishing.
