How Editor.js toolbar works:
1. + button: Hover your mouse to the LEFT of any block — a blue + icon appears. Click it to add a new block.
2. ⋮ button: Click INSIDE a block — a settings icon appears to the RIGHT. Click it for block options (delete, move, convert).
3. Inline toolbar: Select/highlight text — a floating toolbar with Bold/Italic/Link appears.
4. Press Enter at the end of a block to create a new paragraph, then type / to open the block type menu.
